# Contrastive Sketching

A workspace for CLIP-guided sketch-generation approaches. Each approach lives in its own top-level directory with its own environment, README, and CLAUDE.md — treat each as self-contained.

## Approaches

- **[clipasso/](clipasso/)** — Contrastive CLIPasso: CLIP-guided Bézier-stroke sketch generation, extended with a contrastive mode (target + distractor → sketch that repels the distractor). See [clipasso/README.md](clipasso/README.md) for installation and usage.

When working inside an approach directory, `cd` into it first — commands and relative paths documented in that approach's own README assume it is the working directory.
